# Netflix Movies and TV Shows EDA Project

## Project Overview
This project analyzes Netflix Movies and TV Shows data.

## Dataset
Netflix Movies and TV Shows Dataset from Kaggle.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Analysis
- Data Cleaning
- Missing Values
- Movies vs TV Shows
- Country Analysis
- Genre Analysis
- Release Year Analysis
- Rating Analysis
- Movie Duration Analysis
